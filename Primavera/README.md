# Pasta Primavera — Regularização de Cliente (2 anos sem guias INSS / IRPS)

Conteúdo destinado a ser copiado para **`D:\Primavera`**.

| Ficheiro | Para quê |
|---|---|
| `01-lista-documentos-solicitar-cliente` | Checklist completa dos documentos a pedir ao cliente |
| `02-carta-solicitacao-documentos-cliente` | Carta formal ao cliente a pedir os documentos (anexar a lista 01) |
| `03-carta-inss-perdao-juros-mora-e-pagamento-prestacoes` | Requerimento ao INSS: perdão de juros de mora/multas + pagamento em prestações, com mapa da dívida |
| `04-carta-contabilista-anterior` | Pedido de passagem de pasta ao contabilista anterior (opcional) |
| `05-plano-de-regularizacao` | Plano de trabalho por fases e prazos correntes |

Cada documento existe em **`.md`** (texto) e em **`.docx`** (Word, pasta `docx/`), pronto a
editar, imprimir em papel timbrado e assinar. Preencha os campos entre `[...]`.

### Como copiar para D:\Primavera (Windows)

1. Descarregar o repositório (GitHub → *Code* → *Download ZIP*) ou fazer `git pull`.
2. Copiar o conteúdo da pasta `Primavera` para `D:\Primavera`.
   Em PowerShell: `Copy-Item -Recurse .\Primavera\* D:\Primavera\`
